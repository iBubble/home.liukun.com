🧪 NodeLocalChecker 检测数据持久化测试

测试说明

此测试用于验证检测完成后，点击确认对话框时数据是否会消失的问题。

问题描述：检测完毕后能看到各项数值，但点击确认对话框后，各项数值全部消失。

修复方案：确保检测数据正确保存到 nodes 数组，并在重新渲染时正确显示。

测试步骤

  1. 打开 NodeLocalChecker 页面
  2. 导入节点配置
  3. 选择几个节点进行检测
  4. 等待检测完成，观察延迟、IP、纯净度等数据是否显示
  5. 点击确认对话框
  6. 验证：数据是否仍然显示

修复内容

✓ 修复1：在 checkNode 函数中，确保检测结果正确保存到 nodes 数组 
// 更新 nodes 数组中的数据
node.available = result.available ? 1 : 0;
node.latency = result.latency || null;
node.real_ip = result.real_ip || null;
node.last_check_time = new Date().toISOString().slice(0, 19).replace('T', ' ');

// 保存纯净度数据
if (result.purity && result.purity.score !== undefined) {
    node.ip_purity_score = result.purity.score;
    node.purity = result.purity;
}
✓ 修复2：在 displayNodes 函数中，改进数据显示逻辑 
// 检查节点是否已检测（available 为 0 或 1）
if (node.available === 1) {
    // 可用节点 - 显示延迟、IP、纯净度
    statusBadge = '可用';
    latencyText = node.latency || '-';
    realIpText = node.real_ip || '-';
    // ... 显示纯净度数据
} else if (node.available === 0) {
    // 不可用节点
    statusBadge = '不可用';
} else {
    // 未检测过
    statusBadge = '待检测';
}

快速测试

详细测试指南

  1. 导入节点：
    • 点击"一键导入"按钮，从机场聚合器导入节点
    • 或上传本地 YAML 文件
  2. 选择节点：
    • 勾选 2-3 个节点（不要太多，方便观察）
    • 或点击"全选"按钮
  3. 开始检测：
    • 点击"开始检测"按钮
    • 观察检测进度和状态变化
  4. 检测完成：
    • 等待所有节点检测完成
    • 观察表格中是否显示：延迟、真实IP、IP纯净度
    • 记录这些数值
  5. 点击确认：
    • 点击弹出对话框的"确定"按钮
    • 关键验证：检查表格中的数据是否仍然显示
    • 延迟、IP、纯净度应该保持不变
  6. 额外验证：
    • 尝试切换排序方式（按延迟、按纯净度等）
    • 尝试切换国家筛选
    • 数据应该始终保持显示

预期结果

✓ 检测完成后：
  • 延迟数据正常显示（如：123ms）
  • 真实IP正常显示（如：1.2.3.4）
  • IP纯净度正常显示（如：85分 (良好)）
✓ 点击确认后：
  • 所有数据保持显示，不会消失
  • 可以正常排序和筛选
  • 刷新页面后数据仍然存在（已保存到数据库）
