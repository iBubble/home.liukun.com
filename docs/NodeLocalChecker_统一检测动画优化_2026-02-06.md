## 📋 优化概述

将原来每个节点单独显示的小动画改为统一的大型检测进度弹窗，以更直观的方式展示检测进度和实时统计信息。

## ✅ 完成的工作

### 1. 新增检测进度弹窗

**位置**: 全屏居中显示

**组件结构**:
```
检测进度弹窗
├── 标题区域
│   ├── 主标题: "🚀 节点检测中"
│   └── 副标题: 检测说明
├── 视觉区域
│   ├── 雷达扫描动画 (左侧)
│   │   ├── 3个同心圆 (脉冲动画)
│   │   ├── 旋转扫描线
│   │   └── 中心发光点
│   └── 进度信息 (右侧)
│       ├── 检测统计 (已检测/总数)
│       ├── 进度条 (带百分比)
│       └── 详细信息
│           ├── 可用节点数
│           ├── 不可用节点数
│           └── 预计剩余时间
```

### 2. 雷达扫描动画

**特点**:
- 3个同心圆，依次脉冲发光
- 旋转扫描线，360度循环
- 中心发光点，持续脉冲
- 赛博朋克科幻风格

**动画效果**:
- `radar-scan`: 扫描线旋转 (3秒/圈)
- `pulse-glow`: 圆圈脉冲发光 (2秒/次)
- `gradient-shift`: 进度条渐变流动 (2秒/次)

### 3. 实时进度更新

**更新内容**:
- ✓ 已检测数量 / 总数量
- ✓ 进度百分比 (精确到0.1%)
- ✓ 可用节点数 (绿色高亮)
- ✓ 不可用节点数 (红色高亮)
- ✓ 预计剩余时间 (动态计算)

**计算逻辑**:
```javascript
// 平均检测时间
avgTime = 已用时间 / 已检测数量

// 预计剩余时间
remaining = (总数 - 已检测) * avgTime
```

### 4. 移除的功能

**原有动画**:
- ❌ 每个节点的检测中动画
- ❌ 每个节点的成功动画
- ❌ 每个节点的失败动画
- ❌ 表格行的动画效果

**保留功能**:
- ✓ 节点状态更新 (徽章颜色变化)
- ✓ 延迟和IP信息显示
- ✓ IP纯净度信息显示
- ✓ 后台检测逻辑完全不变

## 🔧 技术实现

### 进度计算

```javascript
// 百分比
const percent = (checked / total * 100).toFixed(1);

// 平均时间
const elapsed = (Date.now() - startTime) / 1000;
const avgTime = elapsed / checked;

// 剩余时间
const remaining = (total - checked) * avgTime;
```

### 时间格式化

```javascript
if (remaining < 60) {
    // 小于1分钟: "30秒"
    display = `${Math.ceil(remaining)}秒`;
} else {
    // 大于1分钟: "2分30秒"
    const minutes = Math.floor(remaining / 60);
    const seconds = Math.ceil(remaining % 60);
    display = `${minutes}分${seconds}秒`;
}
```

### 动画关键帧

```css
/* 雷达扫描 */
@keyframes radar-scan {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}

/* 脉冲发光 */
@keyframes pulse-glow {
    0%, 100% {
        box-shadow: 0 0 5px rgba(0, 255, 255, 0.5);
        opacity: 0.6;
    }
    50% {
        box-shadow: 0 0 20px rgba(0, 255, 255, 0.8);
        opacity: 1;
    }
}

/* 渐变流动 */
@keyframes gradient-shift {
    0% { background-position: 0% 50%; }
    50% { background-position: 100% 50%; }
    100% { background-position: 0% 50%; }
}
```
