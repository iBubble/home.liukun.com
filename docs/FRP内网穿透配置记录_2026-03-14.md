# FRP 内网穿透配置记录

## 📅 记录日期
2026-03-14

## 🔍 背景说明
为了确保内网服务器 `ibubble.vicp.net` 能够通过公网稳定访问，用户对 FRP (Fast Reverse Proxy) 进行了配置更新，将其成功引导至新服务器 `47.103.55.200`。

## 📂 关键路径与结构回顾

| 项目 | 绝对路径 |
| :--- | :--- |
| **程序执行文件** | `/home/gemini/frp/frp_0.61.1_linux_amd64/frpc` |
| **配置文件** | `/home/gemini/frp/frp_0.61.1_linux_amd64/frpc.toml` |
| **Systemd 服务定义** | `/home/gemini/frp/frpc.service` |

## ⚙️ 配置详情 (`frpc.toml`)

```toml
serverAddr = "47.103.55.200"
serverPort = 7000

[[proxies]]
name = "home-web-https"
type = "https"
localIP = "127.0.0.1"
localPort = 8443
customDomains = ["home.liukun.com"]
```

## 🚀 服务管理命令
- **启动服务**: `sudo systemctl start frpc`
- **停止服务**: `sudo systemctl stop frpc`
- **重启服务**: `sudo systemctl restart frpc`
- **查看状态**: `sudo systemctl status frpc`
- **开机自启**: `sudo systemctl enable frpc`

## 📝 变更影响
该配置通过 `frp.liukun.com`（对应服务器 `47.103.55.200`）实现了对内网 8443 端口的 HTTPS 映射，域名为 `home.liukun.com`。
