# 宝塔面板 PHP 函数配置指南

## 问题描述
Aggregator 项目需要使用 PHP 的系统执行函数来启动后台扫描任务,但宝塔面板默认禁用了这些函数以提高安全性。

## 需要启用的函数
- `exec` - 执行外部程序
- `shell_exec` - 通过 shell 执行命令
- `proc_open` - 执行命令并打开文件指针
- `popen` - 打开进程文件指针
- `system` - 执行外部程序并显示输出
- `passthru` - 执行外部程序并显示原始输出

## 配置方法

### 方法 1: 通过宝塔面板 Web 界面 (推荐新手)

#### 步骤 1: 登录宝塔面板
1. 打开浏览器访问: `http://你的服务器IP:8888`
2. 输入用户名和密码登录

#### 步骤 2: 进入 PHP 设置
1. 点击左侧菜单 **"软件商店"**
2. 在已安装列表中找到 **"PHP 8.2"** (或你使用的版本)
3. 点击右侧的 **"设置"** 按钮

#### 步骤 3: 修改禁用函数
1. 在弹出的窗口中,点击 **"禁用函数"** 标签
2. 你会看到一个函数列表,每个函数右侧有删除按钮
3. 找到并删除以下函数:
   - `exec`
   - `shell_exec`
   - `proc_open`
   - `popen`
   - `system`
   - `passthru`
4. 点击每个函数右侧的 **红色删除按钮**

#### 步骤 4: 保存并重启
1. 删除完成后,点击 **"保存"** 按钮
2. 点击 **"服务"** 标签
3. 点击 **"重载配置"** 或 **"重启"** 按钮

#### 步骤 5: 验证配置
在服务器上运行:
```bash
php -r "echo exec('whoami');"
```
如果输出用户名(如 `www`),说明配置成功。

### 方法 2: 通过命令行配置 (推荐高级用户)

#### 自动配置脚本
我们已经为你准备了自动配置脚本:

```bash
cd /www/wwwroot/ibubble.vicp.net/Projects/Aggregator
bash enable-php-functions.sh
```

脚本会:
1. 自动查找 PHP 配置文件
2. 备份原配置
3. 移除函数禁用
4. 重启 PHP-FPM

#### 手动配置步骤

**1. 查找 PHP 配置文件**
```bash
# PHP 8.2
PHP_INI="/www/server/php/82/etc/php.ini"

# 或者查找其他版本
ls -la /www/server/php/*/etc/php.ini
```

**2. 备份配置文件**
```bash
sudo cp /www/server/php/82/etc/php.ini /www/server/php/82/etc/php.ini.backup
```

**3. 编辑配置文件**
```bash
sudo nano /www/server/php/82/etc/php.ini
```

找到 `disable_functions` 这一行,删除需要启用的函数名。

**修改前:**
```ini
disable_functions = passthru,exec,system,chroot,chgrp,chown,shell_exec,proc_open,proc_get_status,popen,ini_alter,ini_restore,dl,openlog,syslog,readlink,symlink,popepassthru,stream_socket_server
```

**修改后:**
```ini
disable_functions = chroot,chgrp,chown,proc_get_status,ini_alter,ini_restore,dl,openlog,syslog,readlink,symlink,popepassthru,stream_socket_server
```

**4. 重启 PHP-FPM**
```bash
# 方法 1: 使用 systemctl
sudo systemctl restart php-fpm-82

# 方法 2: 使用宝塔脚本
sudo /etc/init.d/php-fpm-82 restart

# 方法 3: 在宝塔面板中重启
```

**5. 验证配置**
```bash
# 测试 exec
php -r "echo exec('whoami');"

# 测试 shell_exec
php -r "echo shell_exec('date');"

# 查看当前禁用的函数
php -r "echo ini_get('disable_functions');"
```

### 方法 3: 仅为特定站点启用 (最安全)

如果你担心安全问题,可以只为 Aggregator 项目启用这些函数:

**1. 创建独立的 PHP-FPM 配置**
```bash
sudo cp /www/server/php/82/etc/php-fpm.conf /www/server/php/82/etc/php-fpm-aggregator.conf
```

**2. 在宝塔面板中为站点指定 PHP 版本**
- 进入 "网站" 管理
- 找到你的站点
- 点击 "设置"
- 选择 "PHP 版本"
- 选择自定义的 PHP 配置

## 安全建议

### 1. 最小权限原则
只启用项目必需的函数,不要启用所有危险函数。

### 2. 目录权限控制
确保 Web 目录权限正确:
```bash
# 目录权限 775
chmod 775 /www/wwwroot/ibubble.vicp.net/Projects/Aggregator/data
chmod 775 /www/wwwroot/ibubble.vicp.net/Projects/Aggregator/logs

# 文件权限 664
chmod 664 /www/wwwroot/ibubble.vicp.net/Projects/Aggregator/api/index.php
```

### 3. 输入验证
在 PHP 代码中严格验证所有输入,使用 `escapeshellarg()` 和 `escapeshellcmd()`。

### 4. 防火墙规则
确保服务器防火墙配置正确,只开放必要的端口。

### 5. 定期更新
保持 PHP 和系统软件包更新到最新版本。

## 常见问题

### Q1: 修改后仍然报错 "Call to undefined function"
**A:** 确保已重启 PHP-FPM,并清除 PHP OpCache:
```bash
sudo systemctl restart php-fpm-82
# 或在宝塔面板中点击 "重启"
```

### Q2: 担心安全问题怎么办?
**A:** 可以考虑以下方案:
1. 使用独立的 PHP-FPM 配置(方法 3)
2. 使用 Cron 任务代替 Web 触发
3. 使用消息队列(如 Redis)实现异步任务

### Q3: 如何恢复原配置?
**A:** 使用备份文件恢复:
```bash
sudo cp /www/server/php/82/etc/php.ini.backup /www/server/php/82/etc/php.ini
sudo systemctl restart php-fpm-82
```

### Q4: 能否使用其他方式实现后台任务?
**A:** 可以,有以下替代方案:
1. **Cron 任务**: 定时执行扫描脚本
2. **消息队列**: 使用 Redis + Worker 进程
3. **Supervisor**: 管理长期运行的后台进程
4. **命令行触发**: 手动运行 `php scan.php`

## 替代方案: 使用 Cron 任务

如果不想启用这些函数,可以使用 Cron 任务:

### 1. 创建 Cron 任务
在宝塔面板中:
1. 点击 "计划任务"
2. 添加任务
3. 任务类型: Shell 脚本
4. 执行周期: 每 30 分钟
5. 脚本内容:
```bash
#!/bin/bash
cd /www/wwwroot/ibubble.vicp.net/Projects/Aggregator
php scan.php >> logs/cron.log 2>&1
```

### 2. 修改前端逻辑
前端不再触发扫描,而是显示上次扫描结果和下次扫描时间。
