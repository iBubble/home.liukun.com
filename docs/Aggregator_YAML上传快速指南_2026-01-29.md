# Aggregator YAML上传快速指南

## 🚀 快速开始

### 1️⃣ 访问页面
打开浏览器访问：https://home.liukun.com:8443/Projects/Aggregator/

### 2️⃣ 上传YAML文件

在控制面板顶部找到 **"上传YAML文件"** 区域：

```
┌─────────────────────────────────────────┐
│  📤 上传YAML文件                         │
│  ┌──────────────┐  ┌──────────────┐    │
│  │ 选择YAML文件 │  │ 上传并验证   │    │
│  └──────────────┘  └──────────────┘    │
└─────────────────────────────────────────┘
```

### 3️⃣ 操作步骤

1. **选择文件**
   - 点击 "选择YAML文件" 按钮
   - 从本地选择你的 `.yaml` 或 `.yml` 文件
   - 文件名会显示在下方

2. **上传验证**
   - 点击 "上传并验证" 按钮
   - 系统自动解析YAML文件
   - 自动验证所有节点延迟

3. **查看结果**
   - 在节点列表中查看所有节点
   - 每个节点显示延迟时间和状态
   - 绿色=快速，黄色=一般，红色=较慢

### 4️⃣ 生成订阅

1. **勾选节点**（可选）
   - 勾选你想要的节点
   - 或者不勾选，系统自动选择最快的50个

2. **生成订阅链接**
   - 点击 "生成订阅链接" 按钮
   - 复制生成的订阅URL
   - 导入到 Clash 客户端

## 📋 支持的文件格式

### ✅ 标准格式
```yaml
proxies:
  - name: "🇺🇸 美国节点"
    server: us.example.com
    port: 443
    type: trojan
    password: xxx
```

### ✅ 紧凑格式
```yaml
proxies:
  - {name: "🇺🇸 美国节点", server: us.example.com, port: 443, type: trojan}
```

### ✅ 支持的协议
- ✅ Trojan
- ✅ VMess
- ✅ VLESS
- ✅ Shadowsocks (SS)
- ✅ ShadowsocksR (SSR)
- ✅ Hysteria2
- ✅ SOCKS5
- ✅ HTTP/HTTPS

## 🎯 常见问题

### Q: 上传后显示"未能解析出有效节点"？
**A**: 请检查：
1. 文件是否为有效的 YAML 格式
2. 文件中是否包含 `proxies:` 字段
3. 节点名称是否包含过滤关键词（续费、到期等）

### Q: 节点数量比预期少？
**A**: 系统会自动过滤以下节点：
- 包含"续费"、"到期"、"过期"等关键词
- 包含"测试"、"客户端"等提示信息
- 包含"禁止"、"停用"等无效节点

### Q: 如何查看验证进度？
**A**: 
- 查看右侧"运行日志"区域
- 日志会实时显示验证进度
- 绿色=成功，红色=错误，蓝色=信息

### Q: 订阅链接在哪里？
**A**: 
- 验证完成后会自动生成
- 在控制面板中间显示
- 点击"复制"按钮即可复制链接

## 💡 使用技巧

### 技巧1: 批量测试节点
1. 上传多个YAML文件（一次一个）
2. 系统会累积所有节点
3. 一次性验证所有节点

### 技巧2: 筛选最快节点
1. 验证完成后，点击"排序"下拉框
2. 选择"响应时间"排序
3. 勾选前10-20个最快节点
4. 生成订阅链接

### 技巧3: 按地区筛选
1. 使用"国家/地区"下拉框
2. 选择特定地区（如香港、美国）
3. 只显示该地区的节点
4. 勾选后生成订阅

### 技巧4: 检测节点纯净度
1. 点击"检测纯净度"按钮
2. 系统会检测每个节点的IP质量
3. 纯净度高的节点更稳定
4. 按纯净度排序选择最佳节点
