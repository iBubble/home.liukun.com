# 更新日志 (CHANGELOG)

## [未发布] - 2026-04-21

### 新增
- **订阅来源扩展**: 在聚合任务中新增 `hk1.liukun.com` 服务器订阅源，实现了 HK, HK1, SG, US 四台自定义服务器的完整闭环抓取。
- **抓取优先级优化**: 将自定义服务器的获取逻辑移动到任务的最前端（启动代理前），确保核心节点优先通过直连方式快速归集。
- **统计增强**: 定时任务日志增加对自定义服务器抓取数量的细分统计。

所有对项目的显著修改都将记录在此文件中。

## [未发布] - 2026-02-25

### 修复
- **订阅过滤逻辑优化**: 放宽了 `/api/subscribe` 接口的节点下发标准。除了已通过本地真机测试（localLatency）的节点外，现在会回退到初步验证的延迟数据（latency），确保订阅节点数量与网页仪表盘显示的可用节点数（约 134-136 个）保持一致，解决了订阅链接 node 数量过少的问题。
- **订阅排序增强**: 为订阅输出增加了按纯净度（Purity Score）优先、延迟次之的排序逻辑，提升了订阅的使用体验。

## [未发布] - 2026-02-07

### 优化
- **服务器运行时间显示位置调整**: 将服务器运行时间从独立的状态栏移动到 Header 右侧，放置在 Aggregator.yaml 下载按钮前方，形成更紧凑的布局。
- **状态同步逻辑修复**: 修复了页面加载时服务器运行时间无法显示的问题，现在无论服务器状态如何都会正确获取并显示运行时间信息。

## [未发布] - 2026-02-06

### 新增
- **定时任务日志系统**: 实现了定时任务执行详情的记录功能。
  - 后端：增加 `/api/cron_logs` 接口，将任务耗时、状态、节点数量等存入 `cron_logs.json`。
  - 前端：增加定时任务日志查看弹窗，支持显示下次执行时间及格式化耗时展示。

### 优化
- **项目结构清理**: 移除了冗余的备份文件（`.tar.gz`）、过时的测试脚本及临时数据。
- **UI/UX 改进**:
  - 整合 "Linux.do 导入" 功能至 "全网获取" (Free Style) 流程中。
  - 优化首页按钮布局，提升操作流程度。
  - 更新项目 README，增加详细的技术栈说明、目录结构及 API 文档。

### 修复
- **节点检测逻辑**: 优化了连通性测试与纯净度检测的判定算法，解决了部分节点无法正确显示或检测超时的问题。
- **清除功能**: 修复了"清空所有节点"确认框自动关闭的 Bug。
