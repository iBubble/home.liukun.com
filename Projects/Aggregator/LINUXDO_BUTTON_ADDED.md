# Linux.do 独立导入按钮已添加

## 功能说明
添加了一个独立的"Linux.do 论坛导入"按钮，用于单独测试代理系统功能。

## 按钮位置
在主页面的"仅更新 Github 节点"按钮下方，显示为：
```
🔥 Linux.do 论坛导入 (测试代理)
需要代理访问，用于测试代理系统
```

## 功能特点
1. **独立测试代理**：只执行Linux.do导入任务，不包含其他来源
2. **实时日志**：点击后自动打开日志窗口，显示代理启动和访问过程
3. **状态显示**：按钮会显示"导入中..."状态，防止重复点击

## 工作流程
1. 用户点击"Linux.do 论坛导入"按钮
2. 后端初始化代理池（从seed_proxies.json和validated_nodes.json选择非CN节点）
3. 启动Clash代理（使用香港/新加坡/日本等海外节点）
4. 通过代理访问linux.do论坛
5. 抓取带有"订阅节点"标签的帖子
6. 解析订阅链接和节点
7. 保存到manual_proxies.json
8. 停止代理，完成任务

## 代理系统验证
通过这个按钮可以验证：
- ✅ CN节点是否被正确过滤
- ✅ 代理池是否使用海外节点
- ✅ Clash代理是否正常启动
- ✅ curl通过代理访问是否成功
- ✅ 是否能成功访问被GFW封锁的网站

## 测试方法
1. 访问 https://home.liukun.com:8443/Projects/Aggregator/
2. 点击"🔥 Linux.do 论坛导入 (测试代理)"按钮
3. 查看日志窗口，观察：
   - 代理池准备情况
   - 代理启动状态
   - 访问linux.do的结果
   - 抓取到的节点数量
